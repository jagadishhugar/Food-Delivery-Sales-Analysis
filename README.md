# Food Delivery Sales Analysis — Customer & Sales Focus

## Project files
- `Food_Delivery_Sales_Analysis.ipynb`: expanded notebook with explanations and expected-output notes after every analysis section.
- `food_delivery_orders.csv`: 600 synthetic order records.
- `Project_Report.md`: enhanced academic report with methodology, results, discussion, recommendations, limitations, and group task distribution.
- `README.md`: project setup and execution guide.

## Data notice
The dataset is synthetic and for coursework demonstration only. It is not real company data.

## Requirements
Python 3.9 or newer, pandas, numpy, matplotlib, and Jupyter.

Install:
```bash
pip install pandas numpy matplotlib jupyter
```

## Run
1. Extract this folder.
2. Keep the CSV and notebook in the same folder.
3. Start Jupyter with "jupyter notebook".
4. Open `Food_Delivery_Sales_Analysis.ipynb`.
5. Run all cells in order.
6. Use the displayed output tables to prepare the final findings and presentation.

## Suggested team split
- Member 1: data loading, data quality, preprocessing.
- Member 2: sales KPIs, monthly trend, city analysis.
- Member 3: customer segments, top customers, repeat purchases.
- Member 4: cuisine/channel analysis, findings, recommendations, presentation.

## Important interpretation rules
- Sales revenue and AOV use delivered orders only.
- Cancellation and refund rates use all orders.
- Revenue is not profit; cost data is not provided.
- If replacing the sample CSV, update the report's result figures using the new notebook output.
